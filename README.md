# ARCÉ AESTHETIC

정적 사이트 (Tailwind CSS 3)

## 구조
- `src/build.py` 페이지 HTML 생성 (Tailwind 클래스로 작성)
- `src/reviews.json` 방문자 리뷰 데이터
- `src/input.css` Tailwind 진입 파일
- `tailwind.config.js` 색상·글꼴·브레이크포인트 토큰
- `assets/js/site.js` 인터랙션, 연락처·카카오 채널 주소(`CONFIG`)

## 빌드
```
npm install
npm run build
```
`*.html`과 `assets/css/site.css`가 다시 만들어집니다.
